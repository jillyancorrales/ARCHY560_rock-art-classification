Response:




Short answer: Zernike moments are theoretically a stronger shape descriptor than Hu moments (they're orthogonal, so there's less redundant information, and they tend to discriminate shapes better) [doc1]. But for *your* specific situation — a beginner R user working in Quarto — they're actually **harder to implement**, not easier, because there is no mature, beginner-documented R package that computes shape-descriptor Zernike moments. I want to be upfront about that gap rather than paper over it.

## The key caveat

There are two completely different things called "Zernike moments" in the software world, and it matters which one you find:

1. **Shape-descriptor Zernike moments** (what you want — rotation/scale-invariant numeric features describing a painted motif's outline or filled silhouette) [doc1]. This is implemented in Python's `mahotas.features.zernike_moments()` [doc2][doc1], which is the standard tool computer-vision tutorials use.
2. **Optical wavefront Zernike polynomials** (used in optics/astronomy to describe lens aberrations and telescope mirror errors) [doc3]. This is what the one real R package named `zernike` on GitHub actually does — it's built for interferogram/wavefront analysis, not image shape description, and its README is written for people analyzing telescope mirrors, not archaeological motifs [doc3].

I could not find a CRAN or well-documented GitHub R package that implements shape-descriptor Zernike moments. That's a genuine gap, not something I'm glossing over.

## Two short plain-language readings

1. **Mallick, S. & Bapat, K. (2018, updated 2026). "Shape Matching using Hu Moments" background section + cross-reference — see instead: 10.5 Zernike Moments, *Computer Vision* course notes blog.** https://cvexplained.wordpress.com/2020/07/21/10-5-zernike-moments/ — ~15–20 min [doc1]. This is the clearest plain-language explanation I found: it directly contrasts Zernike moments with Hu moments (which you already read about), explains orthogonality in one paragraph without heavy math, and gives honest pros/cons ("requires very precise segmentation," "only good for simple 2D shapes") that you can cite directly in a methods-limitations section.

2. **Tutorialspoint. "Mahotas – Zernike Moments."** https://www.tutorialspoint.com/mahotas/mahotas_zernike_moments.htm — ~10 min [doc2]. A short, concrete, syntax-first page showing exactly what `zernike_moments(image, radius, degree)` returns and how changing radius/degree changes the output vector — useful as a second, more mechanical companion to the first reading.

I was not able to verify a true "beginner textbook chapter" (under 20 pages) on Zernike moments the way I could for k-means with ISLR — this method just doesn't have that kind of intro-stats-textbook treatment. The original math-heavy source is Teague (1980), *J. Opt. Soc. Am.* 70(8):920–930, referenced in [doc1] and [doc4], but that is not beginner-accessible.
